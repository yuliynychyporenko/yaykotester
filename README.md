# 🥚 EGG-QA — Система автоматичного тестування якості курячих яєць

## Опис
Консольна програма на C++ для автоматичного тестування та класифікації курячих яєць за параметрами якості.

## Функціонал
- ✅ Тестування яйця за кольором, станом, розміром, вагою та свіжістю
- ✅ Автоматична класифікація (Схвалено / Обмежено / Відхилено / Потрібне миття)
- ✅ Збереження даних у файл
- ✅ Статистика та фільтрація результатів
- ✅ Демо-режим для тестування

## Технології
- C++17
- Visual Studio 2026
- Windows API

## Встановлення
1. Склонуй репозиторій
2. Відкрий `YAYKOTESTER.cpp` у Visual Studio
3. Збери проект (Ctrl+Shift+B)
4. Запусти (Ctrl+F5)
